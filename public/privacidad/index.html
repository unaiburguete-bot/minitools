Política de privacidad

Esta política explica cómo Clicivo trata datos y tecnologías de medición. Última revisión: 2026-08-02.

Responsable y contacto

El proyecto es gestionado editorialmente por Zurekin Comunicación, con base en Bilbao, Bizkaia, España. Puedes contactar en info@zurekincomunicacion.com.

Datos introducidos en herramientas

Los cálculos y transformaciones se ejecutan en el navegador. Los valores, textos, documentos e imágenes introducidos no se envían a Clicivo ni se guardan en una base de datos del sitio. Algunas herramientas cargan bibliotecas JavaScript desde redes de distribución externas; el código de Clicivo no transfiere a esas bibliotecas los archivos seleccionados.

Google Analytics

Clicivo utiliza Google Analytics para conocer el uso agregado de las herramientas, detectar errores y mejorar la experiencia. La etiqueta se configura con el consentimiento denegado por defecto y se integra con el sistema de consentimiento de Google.

Google AdSense y publicidad

Clicivo puede utilizar Google AdSense para mostrar publicidad. Google y sus proveedores pueden tratar información técnica, identificadores y datos de uso para medición, seguridad, limitación de frecuencia y, cuando exista consentimiento, personalización publicitaria. La publicidad no altera el resultado de las herramientas.

Consentimiento

Para usuarios del Espacio Económico Europeo, Reino Unido y Suiza, Clicivo utiliza la plataforma de gestión del consentimiento de Google. El mensaje permite consentir, no consentir y gestionar opciones. Cuando esté publicado, Google mostrará también un enlace para revisar o retirar la elección.

Contacto y conservación

Los mensajes enviados al correo de contacto se utilizan para responder y resolver la consulta. Se conservan durante el tiempo necesario para gestionar la comunicación y cumplir obligaciones aplicables.

Derechos

Puedes solicitar información, acceso, rectificación, supresión, oposición, limitación o portabilidad cuando corresponda mediante el correo indicado. También puedes presentar una reclamación ante la autoridad de control competente.

Proveedores y enlaces

Consulta la política de cookies y la página de publicidad y afiliación para ampliar información.

Clicivo

Calcula, compara y presenta resultados con claridad. Herramientas gratuitas, rápidas y preparadas para trabajar desde cualquier dispositivo.

Cómo utilizar esta herramienta

Selecciona los archivos

Elige los documentos o imágenes desde tu dispositivo. Revisa el tamaño y el formato admitido.

Ajusta las opciones

Ordena, selecciona páginas, define formato, tamaño o calidad según la herramienta.

Descarga el resultado

El procesamiento se realiza en el navegador. Guarda el archivo y cierra la página para liberar memoria.

Fórmula y metodología

El orden visual define la secuencia del PDF final; cada página conserva el contenido original y aplica la rotación seleccionada.

Ejemplo práctico

Carga un PDF, arrastra la página 4 a la primera posición, gira la página 2 y elimina una hoja en blanco antes de descargar.

La herramienta muestra las variables que utiliza y separa las estimaciones de los datos introducidos. En materias económicas, laborales o fiscales, contrasta siempre el resultado con documentación y asesoramiento adecuados.

Preguntas frecuentes

¿Puedo deshacer una eliminación?

Mientras no exportes, puedes volver a cargar el PDF y empezar de nuevo.

¿Las miniaturas reducen la calidad final?

No. Solo sirven como vista previa; el PDF exportado copia las páginas originales.

¿Puedo duplicar páginas?

Esta versión permite ordenar, girar y eliminar. La duplicación se incorporará en una mejora futura.

¿Dónde se procesa el archivo?

En la memoria del navegador, sin enviarlo a Clicivo.

Cálculo transparente

Fórmula, método y un ejemplo realista

Añadir IVA: total = base × (1 + tipo). Quitar IVA: base = total ÷ (1 + tipo). Cuota = total − base.

Ejemplo práctico

Con una base de 100 € y un IVA del 21 %, la cuota es 21 € y el total 121 €. Si partes de 121 €, la base vuelve a ser 100 €.

Las estimaciones se separan de los datos introducidos. En materias económicas, laborales o fiscales, contrasta el resultado con documentación y asesoramiento adecuados.

Preguntas frecuentes antes de usar la herramienta

¿Qué tipos de IVA incluye?

Incluye accesos a 21 %, 10 %, 4 % y un tipo personalizado. La Agencia Tributaria también contempla tipos o supuestos especiales en determinadas operaciones.

¿Quitar un 21 % es restar el 21 % al total?

No. Para obtener la base desde un total con IVA se divide por 1,21; restar el 21 % produce una cifra distinta.

¿Sirve para Canarias?

No como calculadora de IGIC. Canarias aplica un impuesto diferente con tipos propios.

¿La herramienta decide qué tipo corresponde?

No. Debes seleccionar el tipo aplicable a la operación. Consulta la Agencia Tributaria o asesoramiento fiscal si tienes dudas.

¿Puedo usar un tipo personalizado?

Sí. Permite calcular porcentajes diferentes para supuestos o territorios que quieras analizar, sin afirmar que sean tipos legales aplicables.

¿Puedo guardar este escenario para compararlo después?

Sí. Clicivo permite guardar el escenario en este navegador, recuperarlo más tarde y exportar los datos en PDF o CSV sin crear una cuenta.

CÓMO PUBLICAR ESTA ENTREGA
==========================

1. Descarga una copia de seguridad del repositorio actual:
   GitHub > Code > Download ZIP.

2. Descomprime este ZIP.

3. Abre GitHub Desktop y selecciona el repositorio minitools.

4. Pulsa Repository > Show in Explorer.

5. En la carpeta local del repositorio:
   - conserva la carpeta oculta .git;
   - elimina el resto de archivos y carpetas antiguos;
   - copia dentro TODO el contenido interior de esta entrega.

6. Vuelve a GitHub Desktop.

7. Comprueba que se eliminan archivos antiguos y se añaden los nuevos.
   Debe existir únicamente:
   .github/workflows/deploy.yml

8. Escribe como resumen:
   Clicivo: expansión 10/10, SEO, AdSense y mejoras prioritarias

9. Pulsa Commit to main.

10. Pulsa Push origin.

11. En GitHub > Actions, espera a que “Build and deploy Clicivo” termine en verde.

12. Abre https://clicivo.com/ y pulsa Ctrl + F5.

13. Comprueba:
   https://clicivo.com/ads.txt
   https://clicivo.com/sitemap.xml
   https://clicivo.com/es/youtube/monetizacion/ingresos-youtube/
   https://clicivo.com/es/empleo/liquidacion-laboral/calculadora-finiquito/
   https://clicivo.com/es/pdf/unir-dividir/unir-pdf/
   https://clicivo.com/metodologia/
   https://clicivo.com/privacidad/

14. En AdSense > Privacidad y mensajes:
   - abre el borrador de normativa europea;
   - confirma que aparecen Consentir, No consentir y Gestionar opciones;
   - confirma la URL https://clicivo.com/privacidad/;
   - publica el mensaje.

15. Prueba la web en una ventana de incógnito y comprueba que aparece el mensaje europeo.

16. No solicites revisión de AdSense hasta terminar las pruebas indicadas en CHECKLIST_PUBLICACION.md.
